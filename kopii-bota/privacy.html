Privacy policy

Kopii bazy bota is a private backup tool used only by the owner of the Telegram bot @Tamerlan_ai_bot.

What Google data it uses

It asks only for the Google Drive permission drive.file. With it the tool can see and change only the files it creates itself: a folder named “Копии-базы-бота” and the backup files inside it. It cannot see any other file on the owner's Drive.

What it does with the data

  • Uploads password-encrypted backups of the bot's database to the owner's Google Drive.
  • Moves old backups from that folder to the Drive trash, keeping the latest seven.

Sharing

No data is sold, shared with third parties or used for advertising. The access key is stored only on the bot's server and can be revoked at any time in the Google account settings (Security → Third-party connections).
