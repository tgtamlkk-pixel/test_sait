Kopii bazy bota

A private tool of the owner of the Telegram bot @Tamerlan_ai_bot. Once a night it saves an encrypted backup copy of the bot's database to the owner's own Google Drive, so the data survives if the server fails.

It is used only by the owner. It has no other users and offers no public service.
