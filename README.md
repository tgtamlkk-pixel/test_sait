# Focuse — резиденции и архитектурные дома

Статический сайт на чистом HTML/CSS/JS. Без сборки, без зависимостей.

## Страницы

- `index.html` — главная
- `projects.html` — каталог проектов + калькулятор стоимости
- `faq.html` — вопросы и ответы
- `contact.html` — многошаговая форма заявки, уведомления идут в Telegram-бот

## Запуск локально

Открыть `index.html` в браузере. Или:

```
python3 -m http.server 8000
```

## Публикация

Залито на GitHub Pages. Любой пуш в `main` автоматически обновляет сайт.
